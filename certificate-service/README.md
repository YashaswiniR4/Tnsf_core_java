# TNSIF Project – Certificate Service

## About

This repository contains my **Certificate Service** module developed as part of the **TNSIF Technical Training** program. The Certificate Service is a module of a **Placement Management System** that manages certificate information through REST APIs and stores the data in PostgreSQL.

## Purpose

The Certificate Service is used to manage certificate records. The two main certificate details stored are **Certificate Year** and **College**. The **ID** is automatically generated by the database.

## Application Flow

Postman → REST Controller → Service Layer → Repository Layer → PostgreSQL Database

## Project Architecture

The project follows a layered architecture consisting of Entity, Repository, Service, Service Implementation, and Controller layers.

### Entity Layer

`Certificate.java` represents the certificate data and is mapped to a PostgreSQL table using JPA.

### Repository Layer

`CertificateRepository.java` extends `JpaRepository` and provides database operations without requiring manual SQL for basic CRUD operations.

### Service Layer

`CertificateService.java` defines the operations supported by the Certificate Service.

### Service Implementation

`CertificateServiceImpl.java` implements the service operations and communicates with the repository.

### Controller Layer

`CertificateController.java` exposes REST API endpoints that can be accessed through Postman.

## Main Components

### Certificate.java

The entity class represents the certificate information. It contains the certificate ID, year, and college. The ID is automatically generated using JPA.

### CertificateRepository.java

The repository extends `JpaRepository<Certificate, Long>` and provides predefined methods for database operations such as saving, searching, updating, and deleting records.

### CertificateService.java

The service interface defines the four main operations:

- Add Certificate
- Update Certificate
- Search Certificate
- Delete Certificate

### CertificateServiceImpl.java

This class implements the `CertificateService` interface and contains the service logic. It uses the repository to perform database operations.

### CertificateController.java

The controller handles HTTP requests and provides REST API endpoints for the Certificate Service.

## CRUD Operations

| Operation | HTTP Method | Endpoint | Purpose |
|---|---|---|---|
| Add Certificate | POST | `/certificates` | Add a new certificate |
| Search Certificate | GET | `/certificates/{id}` | Retrieve a certificate by ID |
| Update Certificate | PUT | `/certificates` | Update an existing certificate |
| Delete Certificate | DELETE | `/certificates/{id}` | Delete a certificate by ID |

## Postman API Testing

### 1. Add Certificate

**POST**

`http://localhost:8081/certificates`

Request Body:

```json
{
  "year": 2026,
  "college": "VVIET"
}
```

### 2. Search Certificate

**GET**

`http://localhost:8081/certificates/1`

This retrieves the certificate using its ID.

### 3. Update Certificate

**PUT**

`http://localhost:8081/certificates`

Request Body:

```json
{
  "id": 1,
  "year": 2025,
  "college": "VVIET Mysuru"
}
```

This updates an existing certificate record.

### 4. Delete Certificate

**DELETE**

`http://localhost:8081/certificates/1`

This deletes the certificate record using its ID.
